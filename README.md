## Image Guidelines

### Hero Image

The hero image is one of the most important visual elements of the website.

Recommended characteristics:

* High resolution
* Wide landscape composition
* Strong focal point
* Suitable space for text overlay
* Natural and realistic appearance
* Sri Lankan scenery
* Warm, premium travel aesthetic

Recommended subjects include:

* Sri Lankan coastline
* Sigiriya at sunrise or sunset
* Ella and the surrounding mountains
* Tea plantations
* Tropical landscapes

### Package Images

Package images should clearly represent the experience being promoted.

For example:

* **Cultural Tour** → Sigiriya or Kandy
* **Wildlife Safari** → Leopard or elephant
* **Beach Escape** → Tropical coastline
* **Highlands** → Ella or tea plantations
* **Cultural Heritage** → Dambulla or Polonnaruwa
* **Honeymoon** → Beach sunset or luxury accommodation

Use consistent image quality and visual treatment across all package cards.

### Gallery Images

The gallery should provide visual variety across different types of Sri Lankan experiences:

1. Heritage
2. Mountains
3. Beaches
4. Wildlife
5. Culture
6. Traditional experiences

Avoid using multiple images that look too similar.

## Image Optimization

To maintain good website performance:

* Use appropriately sized images.
* Compress large photographs before deployment.
* Prefer modern formats such as WebP where appropriate.
* Avoid unnecessarily large image files.
* Use lazy loading for images below the fold.
* Keep the hero image optimized because it is loaded immediately.
* Use descriptive `alt` text for meaningful images.

## Logo Assets

The website uses two primary logo versions:

### `logo.png`

Used on the main website header.

Recommended characteristics:

* Transparent background
* Ceylora Trails branding
* Suitable contrast against the header
* Clean and minimal design

### `logo-white.png`

Used on the dark footer.

Recommended characteristics:

* White or light logo
* Transparent background
* Strong contrast against the footer background

### `favicon.png`

Used as the browser tab icon.

Recommended characteristics:

* Square format
* Simple brand symbol
* Clearly visible at small sizes

## Testimonial Avatars

The testimonial portraits are used for fictional customer reviews created specifically for this assessment.

AI-generated or appropriately licensed images can be used.

The images should:

* Look natural and professional
* Match the testimonial context
* Have consistent dimensions
* Use similar lighting and image quality
* Avoid recognizable real-world individuals unless the image is appropriately licensed

## Important

The business, customer reviews, package information, prices, contact details, and other business information on this website are fictional and were created specifically for the Web Developer Practical Assessment.

The image assets should be used only as visual content for this assessment project and should not imply affiliation with real businesses, customers, or organizations.
