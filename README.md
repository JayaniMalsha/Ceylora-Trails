## Image Optimisation Tips

- Use **JPEG** for photos (quality 80–85%), **PNG** for logos/icons
- Compress images using [TinyJPG](https://tinyjpg.com) or [Squoosh](https://squoosh.app) before uploading
- Keep all images under **300KB** where possible for fast loading
- Hero background can be up to **500KB** since it loads first

## Free Stock Photo Sources

- [Unsplash](https://unsplash.com) — search "Sri Lanka", "Sigiriya", "Yala", "Ella"
- [Pexels](https://pexels.com) — great for travel photography
- [Pixabay](https://pixabay.com) — free commercial use
- [Wikimedia Commons](https://commons.wikimedia.org) — many Sri Lanka landmarks available

## Note on Avatars

For reviewer avatars, you may use:
- AI-generated faces from [This Person Does Not Exist](https://thispersondoesnotexist.com) (refresh for new faces)
- Stock photo silhouettes/illustrations as a fallback
- The site will still render correctly even if avatar images are missing — just not ideal visually
